# Sadece bu klasörü düzenle

| Dosya | Ne yaparsın |
|--------|-------------|
| **EsyaAyar.java** | Hasar, hız, dayanıklılık vb. |
| **kilic.png** | Kılıç resmi (16×16, şeffaf PNG) |
| **tr_tr.json** | Türkçe isim |
| **en_us.json** | İngilizce isim |

Bitince üst klasörde (tek-esya-mod):

- Linux / Mac: `./yeniden-derle.sh`
- Windows: `yeniden-derle.bat`

Çıkan jar: `tekesya-1.0.0.jar` → Minecraft `mods` klasörüne.

`src/` altına girme; script senin dosyalarını oraya kopyalar.
